职责：一个纯前端的口译训练网站，开发整体网站的UI框架，包含录音控制区、三个结果展示区、状态提示栏，并确保响应式布局（PC/平板/手机）。
文件结构：
index.html          # 主页面
css/
  style.css         # 全部样式（建议使用Flex/Grid布局）
页面元素要求：
1. 顶部标题栏：项目名称 + 简短说明。
2. 录音控制区：
   -开始录音按钮（绿色）
   -停止录音按钮（红色，初始禁用）
   -录音状态指示（例如“等待开始” / “录音中…” / “处理中…”）
3. 三栏结果区（并排或上下，移动端自动折叠）：
   -原文栏：显示实时识别的英文句子
   -翻译栏：显示实时翻译的中文
   -笔记栏：显示生成的结构化口译笔记（保留缩进、符号、换行）
4. 底部状态栏：显示WebSocket连接状态、API调用状态、错误提示等。
5. “复制笔记”按钮：一键复制笔记内容到剪贴板。
样式要求：
-使用等宽字体（`monospace`）展示笔记，保留空格和换行。
-三栏高度一致，超出滚动。
-移动端适配：录音按钮放大，三栏改为垂直堆叠。
与其他成员的接口约定：
-为其他功能提供全局对象或事件监听，例如：
  javascript
  // 展示原文
  window.displayTranscript = function(text) { ... }
  // 展示翻译
  window.displayTranslation = function(text) { ... }
  // 展示笔记
  window.displayNotes = function(markdownText) { ... }
  // 更新状态消息
  window.updateStatus = function(msg, isError) { ... }
-提供录音开始/停止的 UI 状态切换（例如按钮禁用/启用），供任务2调用。
交付物：
-完整的 `index.html` 和 `style.css`。
-在本地 `npm run dev` 下可见布局（无交互功能时显示占位文本）。
